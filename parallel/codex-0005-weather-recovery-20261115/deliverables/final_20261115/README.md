# 芝加哥 Divvy 雨雪天气恢复分析

本目录包含阶段 A–D 的最终课堂交付材料、复现代码和处理后的数据。计算与 GPU 训练在服务器数据盘完成。原始 Divvy 行程、NOAA 天气与 NDFD 预报保存在服务器 `/root/autodl-tmp/ai-sci/data/raw/`，日级数据和结果表按项目约定保存在数据盘。

## 核心结果

- 分析覆盖 2021-22 至 2024-25 四个冬季，共 485 天。清洗后保留 3,233,071 条行程，其中 506,391 条缺少可用起点站编号，只用于城市总量分析。
- 找到 29 场累计新雪至少 10 mm 的降雪事件，其中 26 场有匹配恢复日。主模型使用 68 个城市级雪后日；站点分析包含 39,236 条站点—事件—日期记录和 577 个站点。
- 在控制雪后天数、冬季、气温、降雨和风速后，残雪每增加 10 cm，临时用户相对匹配晴朗日的恢复比例估计低约 33.5%。95% 区间对应下降约 14.6% 至 48.2%。会员估计接近不变，两类用户的残雪斜率差异明显。
- 站点恢复可探索性地分为三类，平均跨冬季 ARI 为 0.552，最新留出冬季为 0.276。降雪事件分组的逐事件留出 ARI 为 0.177，因此事件分组不宜当成稳定类别。
- 按完整冬季留出的 107 天 GRU 测试中，加入前一天已发布的天气预报后，总骑行量、会员、临时用户的 WAPE 分别为 18.1%、16.3%、26.4%。只用过去天气时分别为 25.8%、22.7%、38.7%。
- 预测相对误差按 `(GT - 预测值) / GT` 计算。前一天预报版的平均日误差分别为 -4.0%、-2.9%、-11.7%，负数表示平均高估。按骑行总量汇总后分别为 +2.2%、+2.8%、+2.1%。

## 研究边界

本轮主问题是雪停后的残余积雪与不同用户群体的恢复差异。降雨进入模型作为控制变量，没有单独建立雨后恢复事件分析。天气来自 O’Hare 机场站，不能代表每条街道的雪况或清雪情况。数据是观察性记录，不能据此认定积雪造成了骑行变化。站点空间分析中，CTA 轨道站和公园距离未显示明显线性关系。加入 43 个社区区固定效应后，样本内 R² 从 0.233 增至 0.364，但还没有留出社区验证。

相关研究已经覆盖广义的共享单车天气韧性、站点周边土地利用、用户群体对降雨的差异，以及将雪深纳入韧性分析。本结果适合作为进一步验证的候选研究贡献，现有证据不足以声称已确认首创或达到顶会论文标准。
