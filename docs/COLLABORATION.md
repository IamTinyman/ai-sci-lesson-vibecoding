# 三方协作约定

本约定依据 2026-11-13 的人类指令建立。服务器项目根目录为 /root/autodl-tmp/ai-sci，服务器 SSH 别名为 codex-gpu。

## 人类统筹

人类负责确定方向、优先级和项目目标，了解阶段报告及最新结论，并根据讨论引导下一步探索。人类对数据的解释与研究判断按实际讨论记录。

## Codex 管理与验收

Codex 与人类讨论方向，将已明确的想法整理为 plans/ 下的方案 Markdown，向下游 agent 派发实现任务，并持续检查进展。

方案写清目标、输入数据、分析方法、实现范围、资源安排、产物和验收条件。需要进一步讨论的科学判断在方案中明确记录。

Codex 根据代码、实际运行证据和输出检查方案与实现的一致性，发现偏差后指引修正，并向人类呈现结果、结论依据及仍需判断的问题。已授权范围内的实现与修复由 Codex 调度，改变研究方向或任务目标时继续与人类讨论。

## 下游 agent 执行

下游执行者为本机 DeepSeek Harness 内使用 OpenCode Go 的 DeepSeek V4.1 会话。以实际接口返回的模型标识核验会话配置。

下游根据方案编写代码和脚本、处理数据、统计分析并开展实验，通过 ssh codex-gpu 在服务器项目目录执行。完成后提交实际命令、文件变化、数据版本、运行结果与未解决的问题。

下游回报放在 reports/agent_runs/ 下，并注明对应方案。对方案的疑问和实现中出现的偏差及时回报 Codex。

## 文件与运行位置

- 服务器 /root/autodl-tmp/ai-sci 保存项目代码、方案、数据、环境、实验输出和报告。
- 本机 /Users/tinyman/BUPT/PHD/2026_2027_1/ai-sci 是人类指定的 Harness 调度入口，保存本机代理指令、项目连接信息和必要的调度文件。
- 本机入口通过 SSH 操作服务器仓库。研究数据和实验计算使用服务器数据盘。
- 原有 HANDBOOK.md 中的进程、环境、显存和增量操作准则继续适用。
- 安装依赖或运行分析前，在服务器项目目录的 Bash 中 source scripts/project_env.sh。网络需要加速时，可按人类指示在该会话 source /etc/network_turbo。

## 方案与回报

方案以 plans/NNNN-topic.md 命名，至少包含目标、输入、执行方法、产物和验收条件。执行回报关联方案路径，保留关键命令、实际结果、文件和差异说明。

Codex 验收检查以下内容。

- 实际输入、数据日期、筛选、聚合与指标是否符合方案。
- 代码、命令和输出能否支持回报中的数值与结论。
- 对资源和文件的操作是否符合项目手册。
- 是否出现方法、范围或解释上的偏差，以及偏差是否得到处理。
- AI 辅助和人类判断是否按实际过程记录。
